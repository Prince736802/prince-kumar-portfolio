# Prince Kumar — Portfolio

Personal portfolio site for Prince Kumar, a 4th-year B.Tech (AI & Machine Learning) student focused on Machine Learning, Data Science, and Computer Vision.

**Live site:** https://prince736802.github.io/prince-kumar-portfolio/

## About

Single-page portfolio built as static HTML/CSS/JS — no build step, no dependencies. Bold red-and-black design with a real profile photo in the hero section. Covers:

- Hero introduction
- Skillset (Languages, Machine Learning, Computer Vision / Edge AI, Data Science, Web/Front-End, Tools)
- How I Work (Explore → Build → Ship process)
- Projects (VisionGuard AI, PropertyCreative AI, Universal Bank Loan Prediction, Customer Segmentation, Spam Email Classifier, Student Performance Prediction)
- Work Experience (YBI Foundation — Data Science & Machine Learning Intern)
- Certifications
- Professional Soft Skills
- Contact

## Features

- Animated hero with floating profile photo, chat-bubble and stats overlay
- Scroll-triggered reveal animations throughout
- Animated skill bars
- **Interactive guide avatar** — a floating animated character that walks visitors through each section as they scroll, with optional text-to-speech narration (toggle via the speaker icon)
- Fully responsive layout

## Tech

- HTML5, CSS3, vanilla JavaScript
- Fonts: Poppins, Inter (Google Fonts)
- Browser-native Web Speech API for the guide's voice narration
- No frameworks, no build tools — open `index.html` directly or deploy as-is

## Deployment

Hosted with GitHub Pages, deployed from the `main` branch, root folder.
